# 通用异构证据：失败诊断、论文与代码对照、实现边界

审阅基线：`065a03d`；日期：2026-09-10。本轮实现不重新划分数据集，不以 CE/OE 题型控制生成，不拟合测试集策略。论文中的方法、仓库中可核查的代码、本项目的设计推断和已经验证的结果分别陈述。

## 结论与本轮两条实现方向

医学 agent 已经能调用分类、分割、检索、生成等不同任务的模型。“支持异构小模型”本身不足以成为创新点。当前更值得研究的是：**不同原生输出的哪些内容有资格成为证据，以及这些证据是否确实进入主模型的上下文**。

本轮将已有异构证据与不确定性方向落实为两个可检验机制：

1. **原生证据的有限表达权限**：先确定同一专家、同一请求的观测变化下仍成立的测量内容，再编译为统一证据。分类分数排序不是疾病诊断；图像横坐标关系不是患者左右侧；不同专家的器官和病灶不能自动拼成病灶定位结论。
2. **受真实上下文预算约束的证据传输**：依据完整提示的 tokenizer、图像展开长度和答案预留空间，逐条保留完整证据，记录实际呈现内容。历史 adopted 数量不能替代实际解码输入。

这是本轮实现的工作定义，不声称复原了无法完整读取的分享会话，也不声称已经证明新颖性或临床收益。空间像素注入和训练式异构适配器仍是独立方向，本轮主实验不启用。

## 最新实验为什么失败

直接依据仓库已有 [451 题结果报告](VQARAD_OFFICIAL_NEW_METHOD_RESULTS_2026-09-10.md)：

| 观察 | 可以得出的判断 | 本轮处理 |
|---|---|---|
| 历史 baseline 64 tokens，新方法 32 tokens，提示也不同 | 原比较无法隔离证据机制的因果效果 | 同一完整清单重新生成 baseline 和三个证据臂；共同提示与 64-token 预算 |
| 严格混合分数 0.4825→0.2163；统一内容解析诊断仍下降 0.0600 | 不只是解析格式问题；不能通过换解析器宣称成功 | 不增加任何题型输出语法；解析规则仅在生成结束后固定使用 |
| 172 次 CheXagent 调用均标 adopted，但最终上下文中没有它们 | 调用和中间接纳统计高估了证据传输 | 每次解码记录 presented、omitted、提示摘要及实际 token 预算 |
| 掩码仅被转成名称、框和比例；visual_views=0 | 分割调用不等于主模型使用空间像素 | 不把本轮文本证据说成 mask-token 或像素对齐方法 |
| 扰动审计增加 522 次 forward | 稳定性检查有成本，稳定也不等于正确 | 分开报告额外调用；只标 observed variation，不承诺真值覆盖 |
| 48 题改善、73 题受损 | 强制调用兼容专家不保证增益 | 先修复公平比较和证据边界，再研究调用价值；本轮不从这批错题拟合门控 |

代码还发现：不确定性展示分支曾提前返回，绕过 `retrieval_answer_context=False` 的答案清理。现统一在所有展示风格之前递归清理检索答案字段，包括扰动替代项。主实验仍排除 source-case 检索，因此不需要另建来源数据集。

## 实现细节与可证伪性

### 1. `evidence_permissions.py`

对同一原生结果及其实际扰动替代项构造观测集合。只保留身份一致的观测；重复身份、缺少明确坐标来源、含义不一致的分数不用于建立关系。

允许的关系是有限、可计算的。例如分数语义相同的两个 finding，只有所有观测满足左分数的下界大于右分数的上界，才产生 `native_score_greater`，且标注 `clinical_ordering=False`。框必须显式声明原图归一化坐标；严格不相交才产生 `image_x_before`，并标注不推断患者侧别。

这里的稳定性是**所观测集合内的稳定性**。若集合扩大，完整谓词算子的许可集合不能增加；展示压缩与最多 8 条关系的选择是另外的预算操作，不能将此单调性不加区分地宣称适用于最终序列化文本。

编译器限制自己输出什么，不能证明自由生成的 LLM 不会越界。因此记录 `free_text_compliance_guaranteed=False` 所表达的含义，不宣称已经实现逐句临床事实验证。既有未接入运行时的 claim verifier 也不是本轮效果证据。

### 2. `evidence_transport.py` 与运行时

逐条尝试完整记录，测量真实完整提示，给整个答案预算留空间；超过字符或 token 预算则整体省略，绝不切断半条证据。主配置按获取顺序处理，避免后到的大记录无声挤掉先到记录。

解码 trace 包含实际呈现的专家与证据 ID、遗漏原因、上下文计数、完整提示摘要。`presented_evidence_count` 与历史 adopted 分开；呈现仍不等于模型在因果上使用。

只有工具明确声明可信的 `minimum_evidence_tokens` 下界时，才在调用前排除必然无法放入的记录。未知输出长度的工具仍可能白调用；代码没有捏造一个通用长度估计或调用收益保证。

LLaVA-Med 计数覆盖当前单图 patch/cls_patch 展开路径。其他后端需提供等价计数接口；不支持的组合明确报错。多图、原生 tensor 通道与 bounded/format-control session 不在本轮 token-budgeted 主协议内。

### 3. 可选的 `native_precision.py`

提供未来原生标注可用时的离线接口，本轮不生成校准数据、不执行拟合，主 runner 拒绝加载精度卡。支持的损失是 classification 的 simultaneous native-score error，按真实 hospital/center/site/scanner 域及患者/图像组聚合；拒绝目标集、代理域和答案 token-F1。

半径候选的分域经验超限损失使用 `(超限组数 + 1)/(组数 + 1)` 修正。没有合格半径或未知域时不给精度许可。这依赖固定预测器、组级交换性、原生真值和有效分组，不是任意域泛化定理，也不是 LTT 高概率保证。

保留该 API 只是为后续独立研究准备；不能将其作为本轮“已校准”“已提升 DG”的贡献。

## 创新性判断与下一步证据

当前可以作为候选贡献的是“原生任务输出→有限测量许可→预算内实际传输”的组合及其可审计实现。独立地看，类型适配、扰动一致性、排序区间、完整记录打包都已有相关思想；本报告不是查新证明。

要形成有说服力的论文，必须展示：在相同专家输出、相同主模型和生成设置下，许可编译相比点值/区间文本是否减少错误引入；这种效果是否在多个任务原生输出上成立；质量、上下文占用和额外调用成本如何变化。若改进完全来自少放证据或修复提示，则应归因于传输修复，而不是宣称新的医学推理能力。

下一次先运行同一完整官方清单的四臂匹配评估，不新增任何数据划分。先检查实际呈现证据、无工具样本一致性、缓存身份与真实输出，再离线使用固定评估器比较。不能先看新的测试错题再修改提示或阈值并继续把结果当一次冻结验证。

## 验证与局限

本轮包含检索答案隔离、完整记录预算、分类关系跨扰动失效、坐标语义、组级原生精度拒绝条件、缓存隔离、题型标签移除及运行时真实呈现统计的测试。新增 LLaVA-Med 测试检查图像 token 展开与完整答案预留。

本环境不具备完整临床模型权重与数据，未重跑 451 题 GPU 实验，所有已有分数均来自提交的历史报告。机制测试通过不等于正确率提高。完整测试结果及运行命令见 [运行说明](GENERIC_EVIDENCE_RUNBOOK.md)。
