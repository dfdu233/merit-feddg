# 域鲁棒异构证据协作：论文审查与算法修订

日期：2026-09-07。状态：完整研究设计，只有部分进入 v0.11；不是性能结论。

现有运行代码审查基于本地 `dbc4af5`；最新服务器结果读取自 `origin/main` 的
`8bdd256`。下文保留调研阶段的完整方案。后续 v0.11 已实现单图有界解码、证据有效期、
源域选择/确认及对照实验；多视图稳定性、语义冲突解析、真正 ROI 工具串联尚未实现。
实际代码和可运行命令以 [v0.11 交接文档](BOUNDED_EVIDENCE_V011.md) 为准。
完整待实施规范见 [服务器实施规范](SERVER_DOMAIN_ROBUST_EVIDENCE.md)。

## 1. 研究目标不变，但问题需要收窄

目标：让冻结的医学通用 VLM 在生成过程中，调用可插拔的分类、分割、检测、生成等专用
模型，并在专家存在训练域偏置时，有限地使用其可靠观察。最终输出仍是开放式回答。

不是：把所有任务改成二分类；要求所有专家给出相同答案；让专家替代主模型；
生成完整答案后再核验；重新训练一个覆盖全部能力的模型；用全 NONE 证明性能成功。

建议研究问题：**在冻结模型和有限推理预算下，如何保留异构专家的互补信息，同时限制
域敏感、任务无关或冲突证据对生成的影响？**

必须区分四类变化：

| 变化 | 例子 | 应对方式 |
| --- | --- | --- |
| 能力不适用 | 给普通临床照片调用组织切片专家 | 能力与输入适配检查，不叫 DG |
| 域变化 | 同一任务的医院、扫描仪、染色变化 | 源域校准、真实留域测试 |
| 语义/任务变化 | 疾病分类变成解剖定位；新增疾病 | 显式范围及开放集分析，不强制预测不变 |
| 通信变化 | 同证据换长文本、第二张图片、不同序列化 | 单独控制实验，不归咎于专家 |

## 2. 当前结果约束

[服务器报告](https://github.com/dfdu233/merit-feddg/blob/8bdd256/runs/native-v010-audit/HANDOFF_RESULT.md)
及 [诊断 JSON](https://github.com/dfdu233/merit-feddg/blob/8bdd256/runs/native-v010-source-diagnostics/llava/33f84d09e0bdb3a1/diagnostics/diagnostic-summary.json)：

- v0.10 是源域诊断与拟合，目标生成数为零。
- 64 张独立源图像，复制原图作为第二张输入使平均 Token-F1 变化为 -0.05095，
  17 例下降、0 例上升。它定位了输入格式混杂因素，未定位具体的模型或实现根因。
- XRV findings 紧凑呈现：10 例平均变化 -0.04175 → +0.00646。
- CheXagent 原问题 +0.01771，EvidenceNeed 改写 +0.00894，各 11 例；不能假定改写更好。
- 检索去掉其他病例答案，平均变化仍为 -0.03062；不是单靠去掉答案就能解决。
- 35–39 个 action/history 条件只有 5 个满足支持要求，两套 robust 策略在检查的
  200 个源状态上都选 NONE。不能继续用稀疏历史分桶来掩盖证据通信未成熟。
- 四个 source group 是代理分组，不是四家医院；同图多次干预不增加独立病例支持。
- 所有变化是词面指标变化，尚不是医学事实改善。

设计决定：固定原图；紧凑、范围明确的观察；CheXagent 保留原问题；检索保留为负面对照；
先检验证据影响，再恢复复杂的工具选择。不是调整门槛直到工具被放行。

## 3. 论文审查：结论、可复用点及边界

年份按正式发表/会议接受状态，不按 arXiv 第一次上传日期。这里只将有正式会刊或
作者明确接受声明的工作标注为相应会议；代码存在不等于已经复现，也不等于提供权重。

### R1. I²MoE — ICML 2025

[论文](https://arxiv.org/html/2505.19190v1) · [官方代码](https://github.com/Raina-Xin/I2MoE)

显式区分独有、冗余和协同信息，用交互专家及弱监督损失学习融合。它是训练式模型，
不是现成外部专家的免训练调度器；本轮未核实可直接复用的医学 checkpoint。

借鉴：互补证据不必相同；必须检验组合是否超过最佳单工具。采用四分支干预诊断，
但不要把分数差值称为已估计的 Partial Information Decomposition。

### R2. Supporting Multimodal Intermediate Fusion with Informatic Constraint and Distribution Coherence — ICLR 2026

[会刊](https://proceedings.iclr.cc/paper_files/paper/2026/hash/c555e1ebfe943237aa8350442315d4a1-Abstract-Conference.html)

研究中间融合与晚期融合，在特定约束及 Lipschitz 等假设下分析泛化误差，提出信息约束和
分布协调方法。本轮未核实独立官方代码或现成权重，不能列为一键可运行基线。

借鉴：不能只问专家各自准不准，也要问接口导致的分布错配。其定理不适用于未经检验的
自由文本证据提示，更不支持“中间融合总优于晚期融合”。

### R3. CoRiM — CVPR 2026

[官方论文](https://openaccess.thecvf.com/content/CVPR2026/papers/Zou_CoRiM_Conflict-driven_Risk_Minimization_for_Dynamic_Multimodal_Fusion_CVPR_2026_paper.pdf)

研究冲突驱动的动态多模态融合。官方全文直读本轮遇到访问错误，只核实了官方检索记录、
论文入口和作者机构发表记录；未核实官方代码/权重，因此不将其具体实现当作已审查代码。

借鉴的研究问题是融合风险，而不是把冲突简化成某个模型的熵。分类空间的分布冲突不能
直接套到一个 mask 与一段描述上；必须先检查它们是否在谈同一个对象、属性、区域和时间。

### R4. ThinkOmni — ICLR 2026

[论文](https://arxiv.org/abs/2602.23306) · [官方代码](https://github.com/1ranGuan/thinkomni)

借鉴：把能力协作放到解码分布上。我们的适配路径是同一个医学主模型读取不同证据，
因此分布天然位于同一个词表，而不是拼接 CheXagent 与 LLaVA-Med 的不兼容 logits。
基础 logit 插值/对比解码本身不是新贡献。

### R5. DeepScan — CVPR 2026

[论文](https://arxiv.org/abs/2603.03857) · [官方代码](https://github.com/YChenL/DeepScan)

免训练扫描、重聚焦、视觉证据辅助推理，复用公开视觉模型。它说明工具的真实空间能力

借鉴：原生空间证据及工具间的数据传递。不照搬其多图输入到当前 LLaVA-Med，

### R6. RD-MLDG — ICLR 2026

[正式论文](https://openreview.net/pdf?id=psJiUopUt7) · [全文](https://arxiv.org/html/2602.23777v1)

## 4. 提议算法：任务条件证据 + 有限解码影响

工作名仅用于文档：Task-conditioned Robust Evidence Decoding（TRED）。
未声称名称唯一、机制首创、已达 SOTA 或已满足 ICLR。

保留现有 registry、CapabilityRequest、EvidenceItem、合法动作、缓存、精确 token 前缀、
专家懒加载与源/目标隔离。主模型和专家参数全部冻结。新核心只增加两项：

1. 将原生观察组织为有任务范围和有效期的证据包，并检查稳定性/冲突。
2. 主模型以受预算约束的分布变化使用证据，而不是让证据上下文接管全部回答。

### 4.1 证据包：统一接口，而非统一标签空间

每条观察保存：`evidence_id / expert_fingerprint / input_fingerprint / capability /
entity / attribute / region / status / native_value / units / provenance /
scope_id / expires_after_block / parent_evidence_ids / transform_id`。

- `status` 至少区分 observed、explicit_negative、unknown、not_applicable。
- 低分类分数、没检测到、空 mask 都不能自动转成“病变不存在”。
- 概念分数与生成模型自报置信度不直接当作校准概率。
- mask/box 使用原图坐标，空间变换须可逆映射；保留原生 artifact，不只留文字摘要。
- provenance 标记同图、同模型、同训练家族或同检索来源；复制结果不能重复计票。
- 非结构化生成文本先作为有来源的描述，不用另一个未经评估的 LLM 强制拆成“事实”。
- 最小版用现有结构化 payload 做确定性转换；不能识别的内容保留 unknown，不伪造语义。

### 4.2 稳定性只在可比观察之间计算

为每个专家和问题类型预先登记少量成像扰动，先在真实源图像上由任务指标/人工复核其
是否保留临床语义。可比较原图与 1–2 个轻微变化；不是新独立病例。

分类看相同概念的分数/排序变化；分割看对齐后的区域/边界变化；生成描述只有可靠的
命题对应时才比较，否则不提供自动稳定性认证。三种能力不能共用未经校准的同一阈值。

不默认采用左右翻转、裁掉病灶、强压缩、破坏染色意义的颜色迁移。变换未经验证时，
只跑 no-stability 消融，不把一个视图的稳定性设置为 1。

检查同一实体、属性、区域、时间上的冲突。类别观察与解剖 mask 是互补，不能因输出
不同而惩罚。高置信主模型与专家不一致也不是直接拒绝理由，否则无法修复高置信错误。

重要限制：这是证据对预声明干扰的鲁棒性，不等价于跨医院 DG。稳定的错误仍是错误。

### 4.3 原生能力组合

至少区分三种评估关系：

- 冗余：同一观察重复出现。去重，不因为两份文本来自同一个模型就增加可靠性。
- 互补：例如定位结果帮助另一个支持 ROI 的专家分析指定区域。
- 冲突：对同一部位同一属性给出相反观察。不能只用两个不可比置信度做胜者全拿。

分割可以向支持 ROI 的下游专家传递真实区域，而不是向主模型添加第二张预测图。
必须验证裁剪适用性；整张胸片训练的专家不能未经验证强制改成局部裁剪输入。
主模型保持原图，获得范围明确的观察。若仅传递 mask 摘要，明确称几何信息利用，
不能声称已经实现像素级能力继承。

### 4.4 同主模型的证据读出与解码

令当前精确前缀为 h，冻结医学主模型为 G。所有分支使用同一张原图 x、问题 q 和 h：

`p0 = G(next_token | x, q, h)`

`pE = G(next_token | x, q, h, compact_valid_evidence)`

默认只需两个分支，共享模型权重但不共享不兼容的 KV cache。不同原生专家由同一主模型
读出到同词表分布，避免训练跨专家词表或视觉特征投影。

`r = clip(log(pE) - log(p0), -b, b)`

`p_lambda = softmax(log(p0) + lambda * r)`

在预声明的 `[0, lambda_max]` 内，选择满足 `KL(p_lambda || p0) <= epsilon_block`
和剩余病例干预预算的最大 lambda。lambda、b、预算的源域选择范围必须先冻结。
最大允许 lambda 不是自动最优；其值由源校准选择，包含 0。

这里的 KL 只约束行为改变，不估计医学正确性。即使分布变化很小，greedy argmax 也可能
翻转，不能由 Pinsker 不等式推出准确率不下降。全 NONE 路径必须与原始生成完全一致；
中途停止干预只停止后续影响，不撤销已经提交的 token。

最小版每个问题先只激活一个相关能力、最多两个工具执行；多工具证据在同一 compact
packet 读出，不为每个专家每个 token 都额外启动一个大模型。只有特定组合消融才分别读出。
不引入长篇 JSON 决策，也不生成整段草稿再核验。

### 4.5 内容作用与格式作用必须分开测

除了 p0/pE，诊断阶段增加 matched-format control：相同来源包装、近似长度和字段结构，
但明确不提供有效观察。再比较真实、打乱、重复、过期证据。control 不是“完美因果隔离”，
因为中性文字本身也可能影响模型；要同时保留原始 p0。

这第三分支默认只用于源诊断和小规模消融，不能隐藏在方法延迟之外。
不通过缩短 EOS、重复参考词或任意延长答案来制造 Token-F1 增益。

## 5. DG 的具体落点与校准

不对全部图像做无条件对齐：医院差异可能伴随患病率变化，强制抹平会删除有效信息。
校准单位是预先声明的“能力 × 问题类别”，而非几十种精确调用历史；保持连续干预收益。

真实 source 分为开发与独立校准组，按患者/图像分组。用 leave-one-source-domain-out
评估固定的证据压缩、稳定性阈值和解码预算。被留出的域不能参与提示目录、检索库、
归一化或阈值选择；需要时再做内层选择，不能在同一留域折边调边报泛化收益。

仅在有支持的条件上比较有限配置：平均事实损失、最差域事实损失、临床重要 harm 和成本。
不将“没有支持”混成“已经证明负收益”；不通过降低样本门槛获得调用。
若全部配置都无法通过，报告未建立有效协作，而不是增加风险惩罚再称 DG 有效。

目标时只读取当前病例，所有参数冻结；不积累目标集统计或更新权重。若以后使用这类方法，
另列 test-time adaptation，不混入严格 DG 主表。

本设计没有分布无关的未知医院保证。统计校准、源域稳健性和成像扰动稳定性是三种不同证据。
最多先验证“在明确的真实留域设置下减少有害专家干预”，不能泛化为临床安全。

## 6. 组合及事实性评估

同图、同问题、同精确前缀运行 NONE、A、B、A+B。连续任务得分 S 使用冻结评测规则：

`gain_pair = S(A+B) - max(S(A), S(B))`

`interaction = S(A+B) - S(A) - S(B) + S(NONE)`

前者回答“是否超过最佳单工具”，后者是依赖所选分数的交互对照量，不是 PID 协同信息。
串联 A→B 与 B→A 另报顺序，不能把顺序不同当成独立患者。

主要评测：人工盲评/复核的命题支持、临床错误与遗漏；同时报告答题完整度、回答率、
回答长度，防止通过少回答获得低幻觉率。词面 F1 是次要指标。
自动事实裁判需要在人工子集上审计，不能让同一主模型同时生成和自证正确。

主要对照：generalist；现有 direct-context；bounded-no-stability；完整方法；
预算/调用率匹配的 no-DG；matched-format；shuffled；重复来源；wrong-scope；
best-single；真正原生数据交接的 pair。跨专家强制一致不作为默认正确做法。

单独记录工具自身任务质量与主模型采用质量。正确原生证据仍损害回答时，优先修桥接；
专家本身错误时，调整其适用范围或更换工具，不能仅增大解码强度。

置信区间按患者/独立图像聚类，分域报告；少数域不能支撑关于“任意新域”的置信结论。
反复观察过的目标集降级为 development，新确认集一次性解锁。

## 7. 创新性与失败条件

不是创新：registry、Agent 工具调用、JSON、置信度相乘、普通对比解码、KL 约束、
测试时增强一致性、源域验证。这些都已有先例。

候选贡献是它们中一个需要实验证明的特定机制：**按任务保留互补的原生证据，
隔离域敏感及通信引入的干扰，再以可测量的有限影响进入冻结主模型解码。**

必须证明：相同预算下优于直接注入；真实证据优于格式/打乱控制；组合超最佳单工具；
稳定性信号确实预测或降低跨域 harm；不是通过全 NONE、缩短回答或换更强主模型获得结果。

下列情形应停止扩大：正确证据也无助；稳定性与事实性无关；收益只来自文字长度；
全部退回基线；组合不超单工具；真实域结果不优于预算匹配无 DG。
此时应诚实缩减论文主张，不能通过更换名字或增加公式保证 ICLR 接收。
