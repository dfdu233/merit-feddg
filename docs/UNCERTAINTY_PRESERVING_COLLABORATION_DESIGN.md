# 保留不确定性的医学专家协作：算法探索草案

日期：2026-09-08。依据本地 bb9ffcc 及已同步 STATUS 的负面实验。
状态：研究设计，不是已实现方法、已证明理论或性能结果。此次不改运行默认值。

## 1. 不变的目标与研究纪律

冻结医学通用 VLM 在生成过程中按需调用分类、分割、定位、检索和生成专家。
专家返回原生观察；主模型仍负责最终回答。域泛化属于证据适用性控制。

不增加样本 ID、已知答案、具体 bad case 对应的关键词或提示规则。
已有 request_scope.py 的词表匹配仅作为有限覆盖诊断基线，不升级为主算法。
工具说明、标签目录、坐标系只能来自模型原始接口或事前固定标准。
旧 canary 已被反复查看，只能用于开发回归，不能再作独立有效性证据。

本设计不训练模型、投影层、价值网络或路由器。允许的源域统计须明确披露：
冻结参数 + 源域非参数校准，不等于完全无标签方法。

## 2. 实验真正暴露的三个问题

1. 能力适配：专家输出是否包含当前问题所需的信息？高质量肺分割不等于病灶定位。
2. 域适配：即使任务匹配，这个专家在当前来源/采集条件下是否可靠？
3. 证据使用：即使观察可靠，VLM 是否把局部、有限的证据扩大成不受支持的完整判断？

旧结果分别出现了范围外调用、零调用门控和图像布局混杂。但当前数据不足以确定
第三点是主要根因；它是必须新验证的研究假设，而不是从个别案例得出的结论。
弱增强下预测稳定不证明正确；复制图像也改变答案不证明证据有价值。

## 3. 核心假设：专家给出的不是一个答案，而是有限精度的测量

现有接口大体为：输出一个分数/掩码/句子，再整体采纳或拒绝。
探索的替代为：输出一组仍可能成立的原生观察，并保留其适用范围。
未知域风险应降低可采纳证据的精度；不必把一个专家所有能力一起清零。

候选论文问题：在异构、可能失效的专家之间，如何保持证据的不确定性与作用范围，
使冻结 VLM 使用它们时不产生额外的无依据确定性？

这不是“置信度加权投票”：专家未必输出相同任务，不能统一 softmax 或多数表决。
也不是事后删掉错误回答：控制发生于下一个内容块生成前，已提交前缀保持不变。

## 4. 定义

- s_t=(x,q,y_<t,M_t)：原图、问题、已生成前缀、已采纳证据记忆。
- S_i：第 i 个冻结专家；k_i：原生能力类型。
- r_t：主模型提出的证据需求，不是它猜测的正确答案。
- z_i=S_i(x,r_t)：原生观察，如分类分数向量、掩码、框、检索条目、专家陈述。
- U_i(x,r_t)：与当前证据及校准约束相容的原生观察集合，即不确定集合。
- H_i(z,r_t)：原生观察 z 能支持的有限命题集合。命题是可单独核验的陈述。
- A_i(s_t)=交集_{z 属于 U_i} H_i(z,r_t)：集合内所有可能观察都支持的内容。

“支持”不能由主模型自信代替。确定性的数值/空间关系用代码计算；
自由语义关系需单独评价，暂不能宣称逻辑上可靠。实现只能对可计算的命题子集承诺。

例如，分类目录只涉及组织外观，则任何 U_i 都不能通过 H_i 自动升级为病因诊断。
分割输出只有器官掩码，则 H_i 不包含病灶存在性；还需要真正的病灶能力。
不同器官或模态只是模型元数据，不允许为某个实验案例追加推理规则。

## 5. 通用在线流程

### 5.1 提出需求

在答案开始及已有内容块边界，冻结主模型从有限能力描述中选择工具或 NONE。
输出受约束的 capability_id 和原生查询；不要自由生成专家、能力和 scope 的组合。
工具需求使用 x,q,前缀，绝不读取标签。暂不增加学习路由或额外大控制器。
若图片模态判别有歧义，保留歧义并拒绝不兼容输入；不要用问题关键词覆盖图像判断。
这一步可能失败，须报告请求正确率和覆盖率，不能归入域风险。

### 5.2 获取有限精度观察

专家仍只执行其原始任务。每个适配器提供：

    observe(image, request) -> NativeObservation
    uncertainty(observation, source_reference) -> NativeUncertainty
    supported_content(uncertainty, request) -> EvidencePacket

NativeUncertainty 记录类型、原生单位、校准来源、支持不足、可计算范围。
并非所有专家必须有相同的不确定性估计；没有估计就明确 unknown。
通用的是组合接口和使用原则，不是强行共享一个标量“可靠概率”。

### 5.3 用域信息控制可用范围

源域参考分为原生特征支持与原生任务误差；不能拿回答 Token-F1 替代掩码误差。
在专家自身冻结特征空间比较当前输入与源域样本，距离仅用于支持检测和分层，
不能直接当作错误概率。距离分层边界在源域确定，不看目标数据分布调参。

有独立来源标签时：在按患者隔离、留一来源的校准流程中估计原生误差分位数，
为受支持的距离层构造嵌套 U。离开已校准范围时置 unknown，不外推覆盖保证。
统计过少时不能凭空生成一个有效 U；源域校准只能支持其假设涵盖的分布族。

无标签时：可构造“观测到的变化集合”，例如允许的弱增强下的输出集合，
但必须标为敏感性分析，不是包含真实答案的置信集合，也不产生正确率证书。
完全未知域中，稳定错误依旧无法由这个集合排除。

### 5.4 传递仍被支持的内容，而非全量工具输出

将 A_i 中与当前需求有关的原生内容写入固定格式 EvidencePacket。
尽量保留数字、坐标和不确定范围，不让专家生成冗长解释。
不用按已知答案构造别名表；请求匹配使用冻结语义接口，并单独量化其错误。
分类、分割、检索等不能互相补造没有测量的属性。

主模型带原图、原前缀、证据包继续生成。第一版保持单张原图，不默认拼图或注入 KV。
提示词只是一种传输实现，不构成模型遵守证据边界的保证。记录每个输出命题的证据
引用、超出范围的新增属性，并通过独立评测检查。原图独立支持的内容可以生成；
不能声称“没有专家证据”就等于“没有视觉依据”。

### 5.5 多专家组合

不同属性的观察可并列输入；只有具备对象身份和坐标对应关系时才能合成关系。
同一属性上的冲突保留为冲突，不作无依据平均，不把两个模型一致当独立证据。
缺少对象对应时不得把一个区域的异常与另一个区域的解剖标签拼成病灶位置。
控制器只有新证据需求才再调用；预算和缓存沿用现有实现。

## 6. 各能力的首版边界

| 能力 | 可实现的证据精度 | 不能自动推出 |
| --- | --- | --- |
| 分类 | 经原生标签校准的候选集合，或保留原生未校准分数 | 非穷尽目录之外的诊断、低分阴性 |
| 分割 | 有原生标签校准时的内/外区域；否则预测区域及未知误差 | 器官掩码就是病灶、普通腐蚀膨胀就是置信区间 |
| 检测 | 框/类别及经验证的定位误差范围 | 未检出就不存在 |
| 检索 | 带来源与相似度的外部观察，只作类比 | source 病例答案就是当前答案 |
| 生成 | 可追溯专家陈述，默认未验证 | 流畅陈述或自信就是可靠证据 |

因此首版最适合在分类和分割两类有可核验原生输出的专家上验证，
保留其他插件但不伪称已有统一的自由文本不确定性证书。

## 7. 数学性质与边界

对固定 H，若 U 包含于 V，则 A(V) 包含于 A(U)。
证明：V 中要求同时成立的条件更多，所以可保留的命题不会增加。
含义：域风险扩大不确定范围时，专家不能反而获得更强的发言权限。
这是设计不变量，不是一个足以发表的新定理，也不证明未知域检测正确。

若真实原生量 z* 属于 U，且 H 的支持关系正确，则 A(U) 中的命题真实成立。
若事件 z* 不属于 U 的概率至多 alpha、支持转换错误概率至多 beta，
则错误采纳概率至多 alpha+beta（并集界；不要求独立）。
但现有数据尚未建立 alpha、beta；多次自适应调用还需要联合/序列控制。
主模型最终自由文本若越过证据边界，上述条件结论不适用于它。
严禁把这个形式化写成“我们保证减少医学幻觉”。

## 8. 与已有方法的区别及创新风险

- [VEP, ACL 2025](https://aclanthology.org/2025.acl-long.205/)：小视觉专家的符号化证据提示。
  因此“把专家输出结构化给 VLM”本身不是新颖性。
- [DnR 作者仓库，标注 CVPR 2026 Highlight](https://github.com/EavnJeong/Draft-and-Refine-with-Visual-Experts)：
  外部视觉专家辅助改进视觉依据。我们的区别不能仅是动态工具调用。
- [MoBE 作者仓库，标注 MICCAI 2026](https://github.com/BioMedIA-MBZUAI/MoBE-A-Test-Time-Modality-Generalization-Method)：
  测试时模态泛化。不能声称此前无人考虑专家域问题。
- [Selective Abstraction, 2026 预印本](https://arxiv.org/abs/2602.11908)：
  降低不确定陈述的具体程度以保留可靠信息。因此“少说具体内容”同样不是新主张。
  候选差异应在异构原生测量的不确定性如何跨域传递到生成前的证据权限，
  而非生成后的文字抽象。本轮核查摘要及 v2 正文，未核实正式录用和可执行仓库。
- [Multi-Distribution Robust Conformal Prediction, 2026 预印本](https://arxiv.org/abs/2601.02998)：
  多来源覆盖针对规定的来源成员/混合分布，并非任意未知域保证。
- [域适配不可能性结果，AISTATS 2010](https://proceedings.mlr.press/v9/david10a.html)：
  说明必须陈述迁移假设，不能靠无标签距离识别任意标签机制变化。

本轮未复制这些论文代码或复现结果。概念邻域拥挤，当前创新性未定，
必须通过实现“原生误差 → 可支持内容 → 生成行为”的非平凡连接与实验来建立。

## 9. 不靠 bad case 的验证顺序

1. 冻结算法、数据纳入规则、源域选择和模型元数据。旧 6 例只测兼容。
2. 在新 source-confirmation 集做机制验证：真实原生证据、同格式空证据、
   同能力错配证据、点估计证据、保留不确定性证据。固定问题、长度、预算与原图。
   纳入范围外任务并报告全体结果；匹配子集只作事前分层分析。
3. 必须同时测原生专家任务质量、证据转换正确率、最终医学答案正确性和完整性。
   “没说任何内容”不能在完整性指标上获利。记录输出长度、调用和端到端时间。
4. 将“人工核验的原生证据”作为独立标注的诊断上界，不将 target 答案注入证据。
   若上界也不能改善，则先定位需求/桥接/主模型使用失败，而不是加重域门控。
5. 有真实来源后比较同一接口：无域控制、整专家拒绝、证据精度控制。
   目标集一次冻结评估，不因单次结果挑选病例、缩短答案或改变阈值。
6. 至少两类原生能力、两类影像、替换一个未用于开发的专家；不能用两种分类器
   代替异构能力验证。按患者分组报告差值置信区间，不能把多次工具调用当独立样本。

首要停止条件：若可靠且匹配的原生证据仍不改善答案，或新方法仅靠少回答降低错误，
则本假设未成立。若粒度控制与简单二元门控无差异，则不能作为关键创新。
