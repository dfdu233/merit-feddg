# v0.10：能力请求—证据传递—域鲁棒选择

日期：2026-09-07。研究实现更新，不是性能提升公告。

## 1. 保持不变的研究目标

建立通用、可插拔的方法，让医学 VLM 在生成前/生成块之间使用小模型的原生能力，
并处理专用模型只在部分数据分布上可靠的问题。主模型仍生成最终自由文本；
分类、分割、检索、生成不被强制转换成统一诊断候选分数。不做生成结束后才核验的流程。

“继承能力”在这里是推理时访问外部能力，不是已经完成权重蒸馏。
“通用”是接口和决策流程可扩展，不意味着现有模型覆盖全部医学模态、任意疾病和三维数据。

## 2. 对 v0.9 负面结果的判断

64 个 source 独立图像组不等于 293 个独立干预病例；133 维特征与 35 个精确条件仍很稀疏。
有支持的主要是 CONCH/retrieval，而具有弱正向信号的 CheXagent 因分域支持不足未进入策略。
这使“工具是否可用”和“选择策略好不好”混在一起，不能只归咎于门控阈值。

`value_mean` 的六次调用没有改善、造成两例词面受损；`value_robust` 全部 NONE
在这一批样本上避免了这些修改，但不是临床安全保证，也不是域泛化性能提升。
CheXagent 单工具 +0.00686 的区间跨零，只值得进一步验证，不能认定其已经有效。
此处单工具指 LLaVA-Med 使用工具证据，不是 CheXagent 独立回答的准确率。

优先顺序：确认小模型给出正确且相关的信息 → 确认主模型用得上 → 学习什么时候调用。
否则更复杂的价值回归只能学习“不调用所有工具”。

## 3. 本次已经实现的算法变化

### 3.1 类型化能力子请求 EvidenceNeed

输入仅为问题和注册的 capability/scope，输出任务类型、子请求文本与未指定的 region。
不读取参考答案，不把生成前缀的猜测当成图像事实，不为全图模型伪造 ROI。

- 生成专家：只请求与问题相关的可见观察，要求至多两个短句；不是完整报告。
- 分类专家：保留固定目录的原生分数语义；不把相似度称为疾病概率。
- 分割/检测：请求支持的结构/对象位置，不把结构分割称为病灶分割。
- 检索：直接嵌入原始问题，不把一段指令模板嵌入为搜索语义。

这是透明的 question-only 模板，而非训练出的语义规划器。当前固定目录和 XRV 适配器
仍不使用 query 改变模型输出；生成专家实际接受新的子请求。原有 generated_prefix 仍可传递，
但 CheXagent 不将其当作诊断证据。暂未实现任意新 claim 的自动实体抽取。

### 3.2 按问题压缩的证据呈现

原始 EvidenceItem 完整保留；单独生成供 VLM 阅读的副本：

- 优先保留与问题显式匹配的条目，平分时保持原生排名；默认每列表最多 2 项。
- 原生分数不重新归一化、不阈值化成阳性/阴性；未提到不等于不存在。
- 生成观察不按字符截断，以免截掉否定或不确定性；超出全局预算的整条记录可被省略。
- 检索的 source 答案默认不展示；同时保留“展示 source 答案”的对照。
- 新 scoped 配置默认只呈现文本，叠加图不是默认必需输入；原图始终存在。

去掉检索答案后，当前检索只提供相似问题/相似度，是有意设置的弱信息对照，
**不是新的知识增强检索方法**。若只有有来源归属的答案能带来事实收益，应在 source 验证后
明确启用，而不是为了避免污染而永久丢掉有用信息。问题词面匹配也不等于医学相关性认证。

入口 `run_value.sh --evidence-profile scoped` 启用上述配置，并继续使用既有连续价值与 LODO
过估惩罚；不是另加两道新门控。原 `run_value.sh` 的原生呈现默认保留，以便对照。
新代码指纹会生成新的实验缓存，不能把旧输出伪装成新配置输出。

### 3.3 配对通信诊断，不靠目标集调参

`run_diagnostics.sh` 在真实 source 图像上执行，先验证 block-NONE 与单次生成 token 完全一致。
再固定同一个前缀与剩余生成预算，比较：

| 对照 | 回答的问题 |
| --- | --- |
| NONE vs 原图 + 原图复制 | 两张图的输入格式本身是否导致退化？ |
| 原生文本 vs scoped 文本 | 无关目录条目、检索答案及冗长信息是否干扰回答？ |
| scoped 文本 vs scoped 文本 + 原图复制 | 增加视图的影响，不混入分割预测质量 |
| scoped 文本 + 原图复制 vs scoped 文本 + 预测叠加图 | 预测几何是否提供额外信息？仍包含不可避免的提示文字差异 |
| 原问题请求 vs能力子请求（生成专家） | 专家是否因原来的请求过宽而提供无关报告？ |
| A、B、A→B，均使用 scoped 文本 | 联合证据是否优于单个工具？ |

同一份真实专家输出重放到不同呈现中，不为文本/叠加图对照重复执行专家。
生成专家的两种请求是真实的两次推理。每个病例完成后写入指纹缓存，原始证据与轨迹均保存。
无第二阶段标签回填；诊断不训练策略、不生成 target。

只在答案确实长于一个块时测试 continuation；不会为短回答强行制造后续 claim。
初始与 continuation 分开汇总，独立图像组才计为支持，额外前缀不能扩充样本数。

### 3.4 两工具的联合与条件收益

在同一状态 s 上分别完成 NONE、A、B、A→B 分支，质量函数为 R：

```
ΔA       = R(y_A)  - R(y_NONE)
ΔB       = R(y_B)  - R(y_NONE)
ΔAB      = R(y_AB) - R(y_NONE)
ΔB|A     = R(y_AB) - R(y_A)
interaction = ΔAB - ΔA - ΔB
```

报告是否超过最好单工具，不只报告多工具调用率。保留负增益和合法空证据；工具运行错误立即
停止本病例，不把异常伪装成零增益。默认预声明 CXR anatomy→CheXagent、CONCH→retrieval；
不兼容时记录跳过，不绕过模态/任务白名单。两工具都使用相同真实图像。

**本次测的是联合证据呈现，不是 A 的掩膜传给 B。** 当前 whole-CXR CheXagent 未声明 ROI
适用能力，不能把它强行当裁剪专家。也没有把 A→B 当成已经训练好的组合动作策略。
如果联合收益存在而第一步收益不足，下一步才将有限、预声明的序列作为复合动作学习。

## 4. 在线流程与域泛化的位置

```
原图 + 问题
  → 模态/任务适配（独立检查；不是 OOD）
  → 当前状态：精确前缀、已采用证据、有序历史
  → 对合法工具构造 EvidenceNeed
  → source 拟合的连续价值选择工具或 NONE
  → 工具返回原生观察 → 选定证据呈现 → VLM 续写同一前缀
  → 达到答案/调用预算后结束
```

source 拟合仍比较同前缀的 NONE/工具完成分支，以连续收益而非“主模型会不会错”的二值标签训练。
域鲁棒版本使用独立组支持检查和留一 source 域过估残差惩罚。无支持或保守价值非正则 NONE。
没有修改“每域至少 8 个独立支持组、至少 2 个域”等现有默认条件来追求放行。

然而真实 DG 的关键不是“多乘一个信任系数”：

1. 数据确实有不同医院/设备/染色或明确来源，且域划分不等于病种划分。
2. 同一工具/呈现/问题类型在多个源域有覆盖，区分工具本身失效与主模型使用失效。
3. 呈现选择、特征维数、回归/惩罚参数只用 source 开发与校准；不能从 target 挑配置。
4. 检索必须整条管线留出：LODO 的训练分支检索库不得用验证折的数据构建。当前 v0.9/v0.10
   仍共享 source bank，只做到 policy-level LODO；修复前必须保留这一限制。
5. 统计目标集不参与阈值选择，并审计小模型预训练数据暴露：数据集外划分不等于预训练未见域。

因此本次保留 DG 框架但不声称已经解决 DG。先产生可信的“工具×状态×呈现×来源”的观测，
才有依据学可迁移增益。不以全 NONE 作为成功终点，也不因全 NONE 而盲目降低惩罚。

## 5. 论文方向与尚未完成的部分

可能的中心问题是：**异构冻结能力如何在分布变化下被可靠地传给生成模型，而非只选择专家名字。**
值得验证的贡献是任务条件化的能力通信、同前缀干预的效用估计，以及对联合能力与迁移失效的统一处理。
当前模板、文本裁剪、接口、安全回退本身不构成 ICLR 级充分创新。

本次未实现：学习式证据投影/LoRA、真正 ROI 数据依赖调用、复合动作部署策略、真实医院数据新增、
fold-isolated 检索拟合、临床事实评分器、新目标集评估。不要在论文或 STATUS 中写成已完成。

按诊断结果选择一个方向继续，不同时增加全部模块：

- 专家观察错误：换任务对齐的小模型/修正适配与模态路由；不要让通信模块替专家编结论。
- 观察正确、相关，但主模型用不好：先验证紧凑呈现；仍失败再考虑只训练薄层 evidence adapter，
  同时冻结专家与主 VLM 主体，需无工具能力保持实验。
- 单工具能用、组合失效：先检查重复/矛盾信息与顺序，再考虑预声明复合动作的联合价值。
- source 有益而跨真实域失效：做整条管线的留域校准、源域覆盖与质量分层，最后才讨论更复杂鲁棒目标。

最低证据链不是更多通过的单元测试，而是：专家原生任务能力、主模型事实收益、组合必要性、
独立真实域迁移、预算匹配的强基线、多随机种子/配对置信区间以及未见能力/模型替换验证。

## 6. 与已有研究的关系（不是首创声明）

- [Visual Sketchpad, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/fb82011040977c7712409fbdb5456647-Paper-Conference.pdf)：使用视觉工具生成中间视觉产物辅助推理。
  对本次的启发是显式测试呈现方式；不能把 GPT-4o 的视觉工具效果直接外推到 LLaVA-Med。
- [VILA-M3, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Nath_VILA-M3_Enhancing_Vision-Language_Models_with_Medical_Expert_Knowledge_CVPR_2025_paper.html)：医学专家与 VLM 的协作/对齐是直接相关方向。
  我们必须证明异构冻结工具的迁移价值，不应把“接入医学专家”单独当新意。
- [Consistent Estimators for Learning to Defer to an Expert, ICML 2020](https://proceedings.mlr.press/v119/mozannar20b.html)：学习何时委托专家已有成熟研究。
  本项目的待验证差别在生成中的原生能力使用、证据通信和跨域条件效用，不是 defer 这个词。
- 其他同状态干预、视觉工具、DG 文献与开源实现索引见 `CAPABILITY_VALUE_DESIGN.md`。

这些论文提供设计线索，不为当前方法效果或任意目标域安全性背书。
