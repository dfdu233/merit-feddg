# Main-table result binding audit (2026-09-24)

This is a manuscript-use gate, **not** a new score table. The original raw outputs and older reports remain intact. A number may be entered in the paper only with its exact denominator, scorer code hash, receiver/checkpoint, generation protocol, and output provenance. A historical baseline scored on the same IDs is useful context but does not by itself establish a same-runtime causal method gain.
